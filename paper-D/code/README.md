# Programs

Each directory has a README with the statement of the paper that a program
supports, the command, and the expected output.

| directory | computations |
|---|---|
| `census/` | the censuses of commuting block maps (radius at most 3 and radius 4), control rows, assembly of the tables of classes |
| `searches/` | fixed and time-periodic words, (W1) families, hidden-bit walls, eigenfields, additive conserved quantities; no walls in 110R |
| `windows/` | window graphs of the 88 classes |
| `reach/` | reach of the edge-move method |

Solution tables and other data files of more than 5 MB are not included; the
programs that produce them are.
